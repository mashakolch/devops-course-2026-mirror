Что удобно в VS Code

1. Source Control (Ctrl+Shift+G) — все изменения видны в одном месте, можно кликнуть на файл и сразу увидеть diff.

2. Open Changes — side-by-side diff открывается в один клик, не нужно вводить `git diff` в терминале.

3. GitLens / File History — можно посмотреть историю конкретного файла и кто изменил каждую строку (blame).

Что удобнее в терминале

1. Squash and merge локально— `git rebase -i HEAD~5` в терминале быстрее и гибче, чем через UI.
